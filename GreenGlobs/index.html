Linear Globs

Type a linear equation. If your line passes through globs, you score points. More globs hit = more points.

Controls

Allowed forms:
y = mx + b (ex: y = 2x + 1, y=-x+3, y=0.5x-2, y=3/2x+1)
x = c (vertical line, ex: x = -4)
